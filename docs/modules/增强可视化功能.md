# 增强可视化功能文档

## 概述

本文档介绍了数据分析工具中增强的可视化功能，包括新的交互式图表类型、功能扩展以及使用示例。增强的可视化功能基于Plotly库构建，提供丰富的交互性和更好的用户体验。

## 新增交互式可视化类型

### 1. 决策树可视化 (decisiontreeclassifier)

#### 功能特性
- 交互式决策树结构图
- 节点信息悬停显示
- 分支路径高亮显示
- 可展开/折叠树节点

#### 使用示例
```python
from Src.DataAnalyzer.ModuleInterfaces.data_visualization import DataVisualization
import pandas as pd

# 创建参数字典
param_dict = {
    "task_type": "classification",
    "model_name": "decisiontreeclassifier",
    "feature": pd.DataFrame({
        'feature1': [1, 2, 3, 4, 5],
        'feature2': [2, 4, 6, 8, 10]
    }),
    "target": pd.Series([0, 0, 1, 1, 1]),
    "interactive": True,
    "label_style": {
        "title": "决策树分类器交互式可视化"
    }
}

# 生成交互式图表
visualizer = DataVisualization(param_dict)
figures = visualizer.plot_chart()
```

### 2. 时间序列可视化 (timeseries)

#### 功能特性
- 交互式时间序列折线图
- 时间范围选择器
- 数据缩放功能
- 多序列对比显示

#### 使用示例
```python
from Src.DataAnalyzer.ModuleInterfaces.data_visualization import DataVisualization
import pandas as pd
import numpy as np

# 创建时间序列数据
dates = pd.date_range('2020-01-01', periods=100, freq='D')
values = np.cumsum(np.random.randn(100))

# 创建参数字典
param_dict = {
    "task_type": "transformer",
    "model_name": "timeseries",
    "feature": pd.DataFrame({
        'date': dates,
        'value': values
    }),
    "interactive": True,
    "label_style": {
        "title": "时间序列数据可视化",
        "x": "日期",
        "y": "数值"
    }
}

# 生成交互式图表
visualizer = DataVisualization(param_dict)
figures = visualizer.plot_chart()
```

### 3. 特征重要性可视化 (featureimportance)

#### 功能特性
- 交互式特征重要性条形图
- 特征排序功能
- 悬停显示详细信息
- 可选择显示Top N特征

#### 使用示例
```python
from Src.DataAnalyzer.ModuleInterfaces.data_visualization import DataVisualization
import pandas as pd
import numpy as np

# 创建特征重要性数据
features = [f'feature_{i}' for i in range(10)]
importance = np.abs(np.random.randn(10))

# 创建参数字典
param_dict = {
    "task_type": "analysis",
    "model_name": "featureimportance",
    "feature": pd.DataFrame({
        'feature': features,
        'importance': importance
    }),
    "interactive": True,
    "label_style": {
        "title": "特征重要性分析",
        "x": "特征",
        "y": "重要性"
    }
}

# 生成交互式图表
visualizer = DataVisualization(param_dict)
figures = visualizer.plot_chart()
```

## 交互式图表增强功能

### 1. 图表联动

多个图表之间可以实现联动，当在一个图表中选择数据点时，其他相关图表会相应更新。

#### 使用示例
```python
# 在一个分析流程中生成多个相关图表
param_dict = {
    "task_type": "clustering",
    "model_name": "kmeans",
    "feature": feature_data,
    "interactive": True,
    "enable_linking": True  # 启用图表联动
}

visualizer = DataVisualization(param_dict)
figures = visualizer.plot_chart()
```

### 2. 自定义主题

支持多种预设主题和自定义主题设置。

```python
param_dict = {
    "task_type": "regression",
    "model_name": "linearregression",
    "feature": feature_data,
    "target": target_data,
    "predict": predict_data,
    "interactive": True,
    "theme": "dark"  # 可选: "light", "dark", "custom"
}
```

### 3. 数据导出功能

交互式图表支持将图表数据导出为多种格式。

```python
param_dict = {
    "task_type": "classification",
    "model_name": "logisticregression",
    "feature": feature_data,
    "target": target_data,
    "predict": predict_data,
    "interactive": True,
    "export_options": {
        "format": ["png", "svg", "html", "csv"],
        "filename": "logistic_regression_results"
    }
}
```

## Web界面集成

### 1. Dash集成

可以将交互式图表集成到Dash Web应用中。

```python
import dash
from dash import dcc, html
from Src.DataAnalyzer.ModuleInterfaces.data_visualization import DataVisualization

# 创建交互式图表
param_dict = {
    "task_type": "regression",
    "model_name": "linearregression",
    "feature": feature_data,
    "target": target_data,
    "predict": predict_data,
    "interactive": True
}

visualizer = DataVisualization(param_dict)
figures = visualizer.plot_chart()

# 创建Dash应用
app = dash.Dash(__name__)

app.layout = html.Div([
    html.H1("数据分析可视化仪表板"),
    dcc.Graph(figure=figures["pred_vs_actual_interactive"])
])

if __name__ == '__main__':
    app.run_server(debug=True)
```

### 2. Streamlit集成

也可以集成到Streamlit应用中。

```python
import streamlit as st
from Src.DataAnalyzer.ModuleInterfaces.data_visualization import DataVisualization

# 创建交互式图表
param_dict = {
    "task_type": "clustering",
    "model_name": "kmeans",
    "feature": feature_data,
    "interactive": True
}

visualizer = DataVisualization(param_dict)
figures = visualizer.plot_chart()

# 在Streamlit中显示
st.title("KMeans聚类分析")
for name, fig in figures.items():
    st.plotly_chart(fig)
```

## 扩展开发指南

### 1. 添加新的交互式图表类型

要添加新的交互式图表类型，请按照以下步骤操作：

1. 在 `Src/DataAnalyzer/visualization/interactive_plots/` 目录下创建新的Python文件
2. 实现绘图函数并使用 `@interactive_plot_registry.register` 装饰器注册
3. 确保函数返回 `Dict[str, go.Figure]` 类型

示例：
```python
# 在 Src/DataAnalyzer/visualization/interactive_plots/new_plot.py 中
import plotly.graph_objects as go
from ..interactive_registry import interactive_plot_registry

@interactive_plot_registry.register("analysis", "newplottype")
def plot_new_interactive(params: Dict[str, Any]) -> Dict[str, go.Figure]:
    figures = {}
    
    # 实现绘图逻辑
    fig = go.Figure()
    # ... 绘图代码 ...
    
    figures["new_plot_interactive"] = fig
    return figures
```

from Src.DataAnalyzer.visualization.interactive import InteractiveVisualization

class CustomInteractiveVisualization(InteractiveVisualization):
    def custom_plot(self):
        # 实现自定义交互式图表

## 最佳实践

### 1. 选择合适的可视化类型

根据数据类型和分析目标选择合适的可视化类型：
- 回归任务：使用散点图、残差图
- 分类任务：使用混淆矩阵、ROC曲线
- 聚类任务：使用散点图、聚类大小图
- 特征分析：使用特征重要性图、相关性热力图

### 2. 优化用户体验

- 为图表添加清晰的标题和轴标签
- 使用适当的颜色方案
- 提供足够的交互控件
- 确保图表在不同设备上都能良好显示

### 3. 性能考虑

- 对于大数据集，使用采样或分页加载
- 避免在同一页面显示过多复杂图表
- 合理使用动画和过渡效果

## 故障排除

### 常见问题

1. **图表无法显示**
   - 检查是否正确设置了 `interactive=True`
   - 确认数据格式是否正确
   - 检查是否有JavaScript错误

2. **性能问题**
   - 对大数据集使用采样
   - 减少图表复杂度
   - 使用WebGL渲染模式

3. **主题不生效**
   - 确认主题名称拼写正确
   - 检查是否在正确的参数位置设置主题
