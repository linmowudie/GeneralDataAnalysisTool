# 清理任务接口文档

## 概述

清理任务模块负责定期清理系统中的临时文件和过期会话，确保系统资源得到有效管理和释放。该模块包含两个主要组件：

1. **CleanupTask类** - 负责定期清理任务的核心逻辑
2. **API接口** - 提供手动触发清理和查询清理状态的HTTP接口

## 核心类：CleanupTask

### 类定义
```python
class CleanupTask:
    def __init__(self, interval: int = 300)
    def start(self)
    def stop(self)
    def _run(self)
    def cleanup_temp_directories(self)
```

### 方法说明

#### `__init__(self, interval: int = 300)`
初始化清理任务实例

**参数：**
- `interval` (int): 清理间隔时间（秒），默认为300秒（5分钟）

#### `start(self)`
启动清理任务线程

#### `stop(self)`
停止清理任务线程

#### `_run(self)`
内部方法，执行定期清理逻辑

#### `cleanup_temp_directories(self)`
清理临时数据目录，包括：
- APIOutput目录下的所有文件和子目录
- TempStorage目录下的所有阶段数据

## API接口

### 获取清理任务状态
```
GET /api/cleanup/status
```

**响应示例：**
```json
{
  "status": "running",
  "interval": 300
}
```

### 立即执行清理任务
```
POST /api/cleanup/run
```

**响应示例：**
```json
{
  "status": "success",
  "message": "清理任务执行完成"
}
```

## 使用示例

### 启动清理任务
```python
from api.cleanup_task import cleanup_task

# 启动清理任务
cleanup_task.start()

# 停止清理任务
# cleanup_task.stop()
```

### 手动执行清理
```python
import requests

# 立即执行清理任务
response = requests.post('http://localhost:8000/api/cleanup/run')
print(response.json())
```

## 配置说明

清理任务在系统启动时会自动初始化并开始运行。清理间隔可以通过修改`cleanup_task.py`中的默认参数进行调整。

## 注意事项

1. 清理任务在后台线程中运行，不会阻塞主程序
2. 清理操作是安全的，不会删除重要数据
3. API接口提供了手动触发清理的途径，便于调试和维护
