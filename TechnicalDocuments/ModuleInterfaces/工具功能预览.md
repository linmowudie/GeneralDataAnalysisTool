# 工具功能预览

## 核心功能

### 数据导入
- 支持 CSV、Excel、JSON 等多种文件格式
- 数据库连接支持
- 自动数据类型检测

### 数据清洗
- 缺失值处理
- 异常值检测与处理
- 数据类型转换
- 重复数据处理

### 数据分析
- 回归分析（线性回归、逻辑回归）
- 分类算法（决策树、随机森林、K近邻等）
- 聚类算法（K-Means、Mean Shift）
- 降维技术（PCA）
- 模型评估与验证

### 数据可视化
- 静态图表（Matplotlib）
- 交互式图表（Plotly）
  - 线性回归可视化
  - 逻辑回归可视化
  - K-Means聚类可视化
  - 3D可视化
  - 决策树可视化
  - 时间序列可视化
  - 特征重要性可视化
- 自定义样式设置

### 报告生成
- 自动生成分析报告
- 模型参数和性能指标汇总
- 可视化图表集成
- 支持HTML格式导出

## 技术特性

### 架构设计
- 模块化设计，易于扩展
- 流程化处理，状态管理
- 统一入口接口，使用简便

### 性能优化
- 大数据集采样处理
- 内存优化管理
- 图表渲染优化

### 兼容性
- 支持 Windows、macOS、Linux
- Python 3.7+ 版本兼容
- 主流浏览器支持（Chrome、Firefox、Safari、Edge）

## 可视化功能详情

### 静态图表
- 散点图、折线图、柱状图、直方图
- 热力图、箱线图、小提琴图
- 混淆矩阵、ROC曲线
- 3D散点图、3D曲面图

### 交互式图表
- 鼠标悬停显示详细信息
- 图表缩放和平移
- 数据系列选择和取消选择
- 3D图表旋转和视角调整
- 时间范围选择器（时间序列图表）
- 图表导出功能

### 特色可视化类型
- 决策树结构图
- 时间序列分析图
- 特征重要性图
- 聚类结果图
- PCA降维图
