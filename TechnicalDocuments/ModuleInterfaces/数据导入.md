# 数据导入模块接口文档

## 概述

数据导入模块位于 `backend/Infrastructures/importers`，提供统一签名的读取接口：`FileImporter`（文件）与 `DbImporter`（数据库）。读取实现统一抛 `ImportError_` 异常，并支持大文件分块读取优化。通常通过工作流 IMPORT 步骤（`ImportComponent`）调用，也可直接使用。

## 类：FileImporter

### 方法

#### read()

读取文件为 DataFrame。

```python
from backend.Infrastructures.importers import FileImporter

read(source, file_type: Optional[str] = None, chunksize: Optional[int] = None, **kwargs) -> pd.DataFrame
```

**参数说明：**
- `source` (Union[str, Path]): 文件路径
- `file_type` (Optional[str]): 文件类型（csv/xlsx/json/html），缺省按扩展名推断
- `chunksize` (Optional[int]): 分块读取大小，用于大文件处理

**返回值：**
- `pd.DataFrame`: 读取的数据

**异常：**
- `ImportError_`: 文件不存在、类型不支持或读取失败时抛出

**说明：**
- 对于大于 100MB 的 CSV 文件，会自动启用分块读取（默认块大小为 10000 行）

## 类：DbImporter

### 方法

#### read()

从数据库读取数据为 DataFrame。

```python
from backend.Infrastructures.importers import DbImporter

read(source: str, db_type: str, db_connection_string: str, query: Optional[str] = None, **kwargs) -> pd.DataFrame
```

**参数说明：**
- `source` (str): 表名（当未提供 query 时作为查询目标）
- `db_type` (str): 数据库类型（sqlite/postgresql/mysql/mssql/oracle/mongodb/redis，缺省从连接串推断）
- `db_connection_string` (str): 数据库连接字符串
- `query` (Optional[str]): SQL 查询语句，缺省为 `SELECT * FROM {source}`

**返回值：**
- `pd.DataFrame`: 查询结果

**异常：**
- `ImportError_`: 缺少连接串、数据库类型不支持或查询失败时抛出

**说明：**
- 数据库连接由处理器自动创建与关闭，无需手动管理
- 支持的数据库类型来自 `backend/Infrastructures/Configs/database_config.json`

### 使用示例

#### 文件导入示例

```python
from backend.Infrastructures.importers import FileImporter

importer = FileImporter()

# CSV 文件导入（类型按扩展名推断）
df = importer.read("data.csv")

# 大文件导入（手动指定分块大小）
df = importer.read("large_data.csv", chunksize=5000)
```

#### 数据库导入示例

```python
from backend.Infrastructures.importers import DbImporter

importer = DbImporter()

# SQLite 数据库导入
df = importer.read(
    "table_name",
    "sqlite",
    db_connection_string="sqlite:///database.db",
    query="SELECT * FROM table_name"
)

# MongoDB 导入
df = importer.read(
    "collection_name",
    "mongodb",
    db_connection_string="mongodb://localhost:27017/database_name"
)

# Redis 导入
df = importer.read(
    "key_name",
    "redis",
    db_connection_string="redis://localhost:6379/0"
)
```

#### 通过工作流导入

```python
from backend.Services import ManualWorkflow
from backend.Services.workflows.context import WorkflowContext
from backend.shared.types import StepName

workflow = ManualWorkflow()
context = WorkflowContext("my_session")

workflow.execute_step(context, StepName.IMPORT, {
    "resource_path": "Data/iris.csv",
    "resource_type": "csv"
})
```
