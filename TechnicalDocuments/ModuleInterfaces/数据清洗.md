# DataCleaning 模块接口文档

## 概述

`DataCleaning` 模块提供多种数据清洗模式，包括标准、严格和宽松模式，也支持自定义参数进行数据清洗。该模块继承自 `CleanData` 基类。

## 类：CleanDataMode

### 构造函数

```python
CleanDataMode(
    df: pd.DataFrame,
    select_mode: str,
    params_list: list[str],
    is_freedom_params: bool = False,
    target_col: str = None
)
```

**参数说明：**
- `df` (pd.DataFrame): 待清洗的数据
- `select_mode` (str): 清洗模式（支持 "standard", "strict", "relaxed"）
- `params_list` (list[str]): 参数列表
- `is_freedom_params` (bool): 是否为自由格式参数，默认为 False
- `target_col` (str): 目标列名，用于分类任务中自动编码字符串目标，默认为 None

### 方法

#### clean_data()

执行数据清洗操作。

```python
clean_data() -> pd.DataFrame
```

**返回值：**
- `pd.DataFrame`: 清洗后的数据

**异常：**
- `ValueError`: 当清洗模式不支持或清洗过程中发生错误时抛出
- `AttributeError`: 当指定的清洗方法未实现时抛出
- `TypeError`: 当清洗方法返回的不是 DataFrame 时抛出

### 支持的清洗模式

#### standard（标准模式）
标准数据清洗流程，处理常见的数据质量问题，如缺失值、重复值等。数值型列使用中位数填充，类别型列使用众数填充。

在标准模式下，如果指定了 `target_col` 参数且该列是字符串类型，系统会自动使用标签编码将其转换为数值类型，以便后续的机器学习任务可以正确处理。

#### strict（严格模式）
严格的清洗流程，会移除更多可能有问题的数据，确保数据质量。删除所有包含缺失值的行和重复行。

#### relaxed（宽松模式）
宽松的清洗流程，仅处理最明显的数据问题，保留更多原始数据。仅删除重复行，保留缺失值。

在宽松模式下，如果指定了 `target_col` 参数且该列是字符串类型，系统会自动使用标签编码将其转换为数值类型。

### 自定义清洗参数

在自定义模式下，可以通过参数列表配置清洗过程。支持的参数包括：

- `columns`: 要保留的列名列表，如 `columns=['A', 'B']`
- `drop_duplicates`: 是否删除重复行，如 `drop_duplicates=True`
- `duplicate_subset`: 去重时参考的列，如 `duplicate_subset=['A', 'B']`
- `handle_missing`: 缺失值处理策略，支持 'drop', 'fill'，如 `handle_missing='fill'`
- `fill_value`: 固定值填充缺失值，如 `fill_value=0`
- `fill_method`: 填充方法，支持 'mean', 'median', 'mode', 'ffill', 'bfill'，如 `fill_method='median'`
- `outlier_method`: 异常值处理方法，支持 'iqr', 'zscore', 'none'，如 `outlier_method='iqr'`
- `outlier_threshold`: 异常值阈值，如 `outlier_threshold=1.5`
- `validate_schema`: 是否启用 schema 验证，如 `validate_schema=True`
- `schema_rules`: 每列的验证规则，如 `schema_rules={'A': {'min': 0, 'max': 100}}`
- `target_col`: 目标列名，用于分类任务中自动编码字符串目标，如 `target_col='target'`

### 字符串目标列自动编码功能

从版本更新开始，数据清洗模块支持对字符串类型的目标列进行自动编码。当目标列包含字符串类别（如 "benign" 和 "malignant"）时，系统会自动使用标签编码将其转换为数值形式（如 0 和 1），以便机器学习模型能够正确处理。

此功能在 `standard` 和 `relaxed` 模式下自动启用，当通过 `target_col` 参数指定了目标列且该列是字符串类型时。

### 使用示例

#### 标准清洗模式

```python
from Src.DataAnalyzer.ModuleInterfaces.data_cleaning import CleanDataMode
import pandas as pd

# 创建示例数据
df = pd.DataFrame({
    'A': [1, 2, None, 4, 5],
    'B': ['a', 'b', 'c', 'd', None],
    'target': ['benign', 'malignant', 'benign', 'malignant', 'benign']
})

# 使用标准清洗模式，并指定目标列
cleaner = CleanDataMode(df, "standard", [], target_col="target")
cleaned_df = cleaner.clean_data()
# 此时target列将被自动编码为数值类型（0和1）
```

#### 自定义清洗模式

```python
from Src.DataAnalyzer.ModuleInterfaces.data_cleaning import CleanDataMode
import pandas as pd

# 创建示例数据
df = pd.DataFrame({
    'A': [1, 2, 3, 4, 5],
    'B': ['a', 'b', 'c', 'd', 'e'],
    'target': ['class1', 'class2', 'class1', 'class2', 'class1']
})

# 使用自定义清洗参数
params = [
    "handle_missing='fill'",
    "fill_method='median'",
    "outlier_method='iqr'",
    "target_col='target'"
]
cleaner = CleanDataMode(df, "custom", params)
cleaned_df = cleaner.clean_data()
# target列将被自动编码为数值类型（0和1）
```

### 扩展自定义清洗方法

可以通过继承 `CleanDataMode` 类并实现自定义方法来扩展清洗功能：

```python
from Src.DataAnalyzer.ModuleInterfaces.data_cleaning import CleanDataMode
import pandas as pd

class CustomCleaner(CleanDataMode):
    def custom_clean_method(self, df):
        # 实现自定义清洗逻辑
        return df.drop_duplicates()

# 使用自定义清洗方法
df = pd.DataFrame({'A': [1, 2, 2, 3], 'B': ['a', 'b', 'b', 'c']})
cleaner = CustomCleaner(df, "custom_clean_method", [], is_freedom_params=True)
cleaned_df = cleaner.clean_data()
```
