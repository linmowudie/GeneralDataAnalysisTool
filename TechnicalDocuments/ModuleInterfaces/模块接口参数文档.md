# 模块接口参数文档

本文档详细描述了数据分析工具中各个模块接口的参数信息，包括参数名、类型、默认值、是否必填以及详细描述。

## 1. 数据导入模块 (DataImport)

### 构造函数参数

| 参数名 | 类型 | 默认值 | 必填 | 描述 |
|--------|------|--------|------|------|
| file_resource | Union[str, Path] | - | 是 | 文件路径或数据库表名（根据模式决定） |
| resource_type | str | - | 是 | 文件类型（csv/json/xlsx）或数据库类型（sqlite/postgresql） |
| db_connection_string | Optional[str] | None | 否 | 数据库连接字符串（仅数据库模式需要） |
| is_database | bool | False | 否 | 是否从数据库导入 |

### 方法参数

#### import_data() 方法
| 参数名 | 类型 | 默认值 | 必填 | 描述 |
|--------|------|--------|------|------|
| chunksize | Optional[int] | None | 否 | 分块读取大小，用于大文件处理 |
| **kwargs | dict | {} | 否 | 传递给具体导入方法的参数 |

#### close_connection() 方法
该方法无参数，用于关闭数据库连接（如果是数据库模式）。

## 2. 数据清洗模块 (CleanDataMode)

### 构造函数参数

| 参数名 | 类型 | 默认值 | 必填 | 描述 |
|--------|------|--------|------|------|
| df | pd.DataFrame | - | 是 | 待清洗的数据集 |
| select_mode | str | - | 是 | 清洗模式（"standard", "strict", "relaxed"） |
| params_list | list[str] | - | 是 | 参数列表 |
| is_freedom_params | bool | False | 否 | 是否使用自定义参数 |
| target_col | str | None | 否 | 目标列 |

### params_list 参数详解

params_list 是一个字符串列表，用于自定义清洗参数。当 is_freedom_params 为 True 时，系统会解析 params_list 中的参数并应用相应的清洗规则。

参数格式为 "key=value" 形式，以下是支持的参数：

| 参数名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| columns | Optional[List[str]] | None | 要保留的列名列表。None 表示保留所有列 |
| drop_duplicates | bool | True | 是否删除重复行 |
| duplicate_subset | Optional[List[str]] | None | 去重时参考的列。None 表示基于所有列 |
| handle_missing | str | 'auto' | 缺失值处理策略：'drop', 'fill', 'auto' |
| fill_value | Any | None | 固定值填充缺失值（优先于 fill_method） |
| fill_method | str | 'mean' | 填充方法：'mean', 'median', 'mode', 'ffill', 'bfill' |
| outlier_method | str | 'iqr' | 异常值处理方法：'iqr', 'zscore', 'none' |
| outlier_threshold | float | 1.5 | 异常值阈值（IQR 倍数或 Z-score 标准差） |
| validate_schema | bool | False | 是否启用 schema 验证 |
| schema_rules | Optional[Dict] | None | 每列的验证规则，如 {'age': {'min': 0, 'max': 100}} |
| return_stats | bool | False | 是否返回清洗统计（预留功能） |
| target_col | Optional[str] | None | 目标列名称，用于分类任务中自动编码字符串目标 |

### 方法参数

#### clean_data() 方法
该方法无参数，执行数据清洗流程并返回清洗后的数据集。

## 3. 数据分析模块 (DataAnalyzer)

### 构造函数参数

| 参数名 | 类型 | 默认值 | 必填 | 描述 |
|--------|------|--------|------|------|
| df | pd.DataFrame | - | 是 | 待分析的数据集 |
| model | str | - | 是 | 模型名称（如 'lr', 'rf', 'xgb', 'svm' 等） |
| random_state | int | 42 | 否 | 随机种子，用于保证结果可复现 |
| is_split | bool | True | 否 | 是否进行数据集分割（训练/测试） |
| split_ratio | float | 0.8 | 否 | 数据集分割比例（如 0.8 表示 80% 训练，20% 测试） |
| feature_cols | Optional[List[str]] | None | 否 | 特征列名称列表，若为 None 则自动排除目标列后所有列 |
| target_col | Optional[str] | None | 否 | 目标列名称 |
| is_return_model_param | bool | False | 否 | 是否返回模型参数（如超参数） |
| metrics_list | Optional[List[str]] | None | 否 | 评价指标列表（如 ['accuracy', 'precision', 'f1']） |
| is_return_model_score | bool | True | 否 | 是否返回模型得分（评估指标结果） |
| is_return_training_set | bool | False | 否 | 是否返回训练集 |
| is_return_model_predicting_set | bool | False | 否 | 是否返回模型预测集 |
| feature_cols_encoding | str | 'onehot' | 否 | 特征列中类别变量的编码方式（如 'onehot', 'label'） |
| target_col_encoding | str | 'label' | 否 | 目标列编码方式（分类任务中使用，如 'label'） |
| test_set | Optional[pd.DataFrame] | None | 否 | 测试集数据集，默认为 None |
| model_params | Optional[Dict[str, Any]] | None | 否 | 模型参数字典，用于覆盖默认参数 |

### model_params 参数详解

model_params 参数是一个字典，用于覆盖模型的默认参数。不同的模型支持不同的参数，以下是一些主要模型的参数说明：

#### 回归模型

##### LinearRegression
| 参数名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| fit_intercept | bool | True | 是否计算截距 |

##### Ridge
| 参数名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| alpha | float | 1.0 | 正则化强度 |
| random_state | int | 42 | 随机种子 |

##### Lasso
| 参数名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| alpha | float | 1.0 | 正则化强度 |
| random_state | int | 42 | 随机种子 |

#### 分类模型

##### LogisticRegression
| 参数名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| C | float | 1.0 | 正则化强度的倒数 |
| max_iter | int | 1000 | 最大迭代次数 |
| fit_intercept | bool | True | 是否计算截距 |
| solver | str | 'liblinear' | 优化求解器 |

##### DecisionTreeClassifier
| 参数名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| max_depth | int or None | None | 树的最大深度 |
| min_samples_split | int | 2 | 分割内部节点所需的最小样本数 |
| random_state | int | 42 | 随机种子 |

##### KNeighborsClassifier
| 参数名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| n_neighbors | int | 5 | 邻近点的数量 |

##### SVC
| 参数名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| C | float | 1.0 | 正则化参数 |
| kernel | str | 'rbf' | 核函数类型 |
| random_state | int | 42 | 随机种子 |

#### 聚类模型

##### KMeans
| 参数名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| n_clusters | int | 3 | 聚类数量 |
| random_state | int | 42 | 随机种子 |

##### MeanShift
| 参数名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| bandwidth | float or None | None | 带宽参数 |

##### DBSCAN
| 参数名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| eps | float | 0.5 | 邻域半径 |
| min_samples | int | 5 | 核心点的最小样本数 |

#### 降维与变换模型

##### PCA
| 参数名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| n_components | int | 2 | 保留的主成分数量 |

##### StandardScaler
无特殊参数

##### MinMaxScaler
无特殊参数

##### TSNE
| 参数名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| n_components | int | 2 | 嵌入空间的维度 |
| random_state | int | 42 | 随机种子 |

### 方法参数

#### analyze() 方法
该方法无参数，直接执行数据分析并返回结果。

#### _validate_inputs() 静态方法
| 参数名 | 类型 | 默认值 | 必填 | 描述 |
|--------|------|--------|------|------|
| df | Union[pd.DataFrame, None] | - | 是 | 待验证的数据集 |
| target_col | Optional[str] | None | 否 | 目标列名称 |
| feature_cols | Optional[List[str]] | None | 否 | 特征列名称列表 |

## 4. 数据可视化模块 (DataVisualization)

### 构造函数参数

| 参数名 | 类型 | 默认值 | 必填 | 描述 |
|--------|------|--------|------|------|
| param_dict | Dict[str, Any] | - | 是 | 包含所有可视化所需参数的字典 |

### param_dict 详细参数说明：

| 键名 | 类型 | 必填 | 描述 |
|------|------|------|------|
| task_type | str | 是 | 任务类型 (classification, regression, clustering, transformer) |
| model_name | str | 是 | 模型名称 (小写) |
| feature | pd.DataFrame | 是 | 特征矩阵 |
| target | pd.Series | 条件必填 | 目标值（classification, regression任务必需） |
| predict | pd.Series | 条件必填 | 预测值（classification, regression任务必需） |
| label_style | dict | 否 | 标签样式 {x: str, y: str, title: str} |
| plot_style | str | 否 | 绘图风格 (matplotlib风格) |
| shape_style | dict | 否 | 形状样式 {points: {size: int, colors: list}, lines: {width: float, styles: list}} |
| font_style | str | 否 | 字体样式 |
| model_specific | dict | 否 | 模型特定参数 (如聚类中心、解释方差等) |
| interactive | bool | False | 否 | 是否使用交互式可视化 |

### 方法参数

#### validate_params() 方法
该方法无参数，用于验证必要参数。

#### plot_chart() 方法
该方法无参数，用于生成图表。

#### _ensure_data_consistency() 方法
该方法无参数，用于确保可视化数据的一致性。

#### _plot_static_chart() 方法
该方法无参数，用于生成静态图表。

#### _plot_interactive_chart() 方法
该方法无参数，用于生成交互式图表。

#### apply_global_styles() 方法
该方法无参数，用于应用全局绘图样式。
